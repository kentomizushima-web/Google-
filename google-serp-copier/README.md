# Google SERP Copier

Google検索結果（SERP）の指定順位範囲からURLを一括取得し、クリップボードにコピーするChrome拡張機能です。  
NotebookLM のウェブソース追加など、複数URLをまとめて貼り付けたいシーンで活用できます。

---

## 機能

- 検索キーワードと取得順位範囲（例: 51位〜100位）を指定してURLを一括取得
- 広告・Googleサービスリンクを自動除外し、オーガニック検索結果のみ抽出
- 取得したURLを改行区切りのプレーンテキストとしてクリップボードにコピー
- 取得中の進捗をリアルタイム表示（「ページ 2/5 を取得中...」）
- Content Script を使わないため、他の拡張機能への影響ゼロ

---

## インストール手順

Chrome 拡張機能はデベロッパーモードで読み込む手順で使用します。Chrome Web Storeへの公開は不要です。

### 手順

1. このリポジトリを任意の場所に保存（またはダウンロード・展開）します。

2. Chrome を開き、アドレスバーに以下を入力してEnterを押します。
   ```
   chrome://extensions
   ```

3. 右上の「デベロッパーモード」トグルを **オン** にします。

4. 「パッケージ化されていない拡張機能を読み込む」ボタンをクリックし、
   `google-serp-copier` フォルダ（`manifest.json` が入っているフォルダ）を選択します。

5. 拡張機能の一覧に「Google SERP Copier」が表示されれば完了です。

---

## 使い方

1. Chromeツールバーの拡張機能アイコン（パズルピース）をクリックし、
   「Google SERP Copier」を選択してポップアップを開きます。

2. **検索キーワード** を入力します。  
   例: `SEOツール おすすめ`

3. **取得開始順位** と **取得終了順位** を指定します。  
   デフォルトは 51位〜100位です。

4. **「URLを取得」** ボタンをクリックします。  
   指定した順位範囲のページを順次取得します（各ページ間に1.5秒の待機あり）。

5. 取得が完了するとURL一覧が表示されます。

6. **「クリップボードにコピー」** ボタンをクリックすると、
   URLが改行区切りのプレーンテキストとしてコピーされます。

7. NotebookLM や任意のテキストエディタに貼り付けてご利用ください。

---

## 取得順位の例

| 開始順位 | 終了順位 | 取得するページ数 |
|:---:|:---:|:---:|
| 1 | 10 | 1ページ |
| 11 | 30 | 2ページ |
| 51 | 100 | 5ページ（デフォルト） |
| 21 | 50 | 3ページ |

---

## 注意事項

- Google検索結果のHTML構造はGoogleの仕様変更により変わることがあります。
  URLが取得できなくなった場合は、`background.js` の `extractUrls` 関数内の正規表現を確認してください。

- 短時間に大量のリクエストを送ると、Googleの自動検出（CAPTCHA）が表示される場合があります。
  各ページ取得間に1.5秒のディレイを設けていますが、目安として1回あたり10ページ（100件）程度が安全な範囲です。

- この拡張機能は個人利用を目的としています。
  取得したURLの利用はGoogleの利用規約の範囲内で行ってください。

## ファイル構成

```
google-serp-copier/
├── manifest.json     # Manifest V3 設定ファイル
├── popup.html        # ポップアップのHTML
├── popup.css         # ポップアップのスタイル
├── popup.js          # ポップアップのUIロジック
├── background.js     # Service Worker（fetch・URL抽出）
├── test_extract.js   # URL抽出ロジックのテストスクリプト（開発用）
└── icons/            # アイコン格納フォルダ（任意で追加）
```

---

## 開発者向け: テストの実行

URL抽出ロジックのユニットテストはNode.jsで実行できます。

```bash
node test_extract.js
```

---

## 技術仕様

| 項目 | 内容 |
|---|---|
| Manifest バージョン | V3 |
| バックグラウンド | Service Worker（`background.js`） |
| Content Script | 不使用（他の拡張機能への影響なし） |
| HTMLパース | 正規表現（Service Worker内でDOMParserは不使用） |
| 必要なパーミッション | `activeTab`, `clipboardWrite` |
| 対象ホスト | `google.com`, `google.co.jp` |
